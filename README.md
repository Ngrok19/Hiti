# 🎂 Hiti Bdy

A simple birthday surprise website created to celebrate a special day with beautiful animations, personalized messages, and an interactive experience.

## ✨ Features

- 🎉 Animated birthday celebration
- 🎂 Beautiful birthday theme
- 💖 Personalized messages
- 🎵 Background music (optional)
- 📸 Photo gallery support
- 📱 Fully responsive design
- ✨ Smooth animations and transitions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/hiti/hiti.git
```

2. Open the project folder

```bash
cd hiti-bdy
```

3. Launch the project

Simply open `index.html` in your preferred web browser.
